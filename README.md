
# AttendX-Test-Scripts

## Project Description
This repository contains basic test scripts for a student attendance
application called AttendX.

## Files

### 1. login_test.py
- Tests valid login credentials.
- Tests rejection of invalid login credentials.
- Displays PASS or FAIL results.

### 2. attendance_test.py
- Tests marking a student's attendance as Present.
- Tests rejection of an invalid attendance status.
- Displays test results in the terminal.

## Requirements
- Python 3 installed
- Git installed
- Visual Studio Code

## How to Run

Run the login test:

```bash
python login_test.py
```

Run the attendance test:

```bash
python attendance_test.py
```
